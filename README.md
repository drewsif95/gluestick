# Gluestick

Fit more photos in one frame. Gluestick lays your photos out as a collage for Stories, posts, carousels and your profile grid, and reads the date and place from each photo.

**Open it:** https://drewsif95.github.io/gluestick/

On iPhone, open the link in Safari and tap **Share › Add to Home Screen** to use it like an app. Your photos stay on your phone: nothing is uploaded.

This repository holds the built website only. It is published with GitHub Pages from the `main` branch.
